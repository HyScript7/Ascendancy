# Ascendancy Documentation

> [!IMPORTANT]
> **This is not the wiki for regular users.** This directory contains documentation written by developers in order to document APIs, design decisions, explain workflows, visualize pipelines and reason their questionable decisions.

> [!NOTE]
> This directory is meant to be viewed and edited using [Obsidian.md](https://obsidian.md/).
> If you do not want to clone the entire project, you can use sparse checkout to clone just this directory:
> ```sh
> git clone --no-checkout <repository url>
> cd Ascendancy
> git sparse-checkout init
> git sparse-checkout set docs/
> git checkout <branch>
> ```
